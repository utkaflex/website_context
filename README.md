# Одностраничный сайт IT-компании

Откройте `index.html` в браузере. Сборка и зависимости не требуются.

## Перед публикацией

- Подтвердите e-mail ООО «Контекст», добавьте точный юридический адрес, ИНН и ОГРН.
- Замените демонстрационные метрики и кейсы только на подтверждённые сведения.
- Заполните политику и отдельное согласие по фактическим процессам и согласуйте с юристом.
- Подключите форму к серверу с первичной записью и хранением данных граждан РФ в базе на территории РФ.
- Проверьте необходимость уведомления Роскомнадзора до начала обработки персональных данных.
- Если подключается аналитика, перечислите cookie и загружайте её только после согласия пользователя.
- Не добавляйте в кейсы логотипы, отзывы и персональные данные без необходимых прав и согласий.

Форма намеренно работает в демо-режиме и никуда не отправляет данные.
