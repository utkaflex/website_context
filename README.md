# Контекст

Статический сайт IT-компании и её первого продукта — системы логистики между складами и строительными объектами. HTML, CSS и JavaScript без сборки и внешних зависимостей.

## Просмотр

Откройте index.html или запустите `python -m http.server 8080 --bind 127.0.0.1` из папки проекта и перейдите на http://127.0.0.1:8080.

## Реализовано

- Адаптивная вёрстка, мобильное меню, клавиатурная навигация, поддержка уменьшенного движения.
- Описание компании, одного продукта и процесса доставки.
- Интерактивная демонстрация трёх этапов рейса. Все данные демонстрационные, интеграции с реальной системой нет.
- Title, description, Open Graph, SVG favicon.
- Нет внешних шрифтов, аналитики, cookie, хранилища браузера или форм сбора данных.

## Перед публичным запуском

1. Указать подтверждённый email или Telegram вместо блока о подготовке контактов.
2. Подтвердить описание возможностей и статус продукта с командой.
3. Добавить фактические сведения о компании без вымышленных реквизитов, адресов, клиентов и показателей.
4. Выбрать домен и хостинг; настроить HTTPS, основной домен, canonical, sitemap.xml и robots.txt.
5. Если появятся форма или аналитика, подготовить документы и обработку данных под фактическую инфраструктуру.

Публикация и подключение домена отложены по запросу пользователя. Сейчас сайт заявки не принимает.
